# CFB Rankings Model Freeze — 2026-10-14

The CFB ranking methodologies and calculations are frozen as of 2026-10-14 by owner request.

Do not alter CFB rankings formulas, component weights, opponent adjustments, conference adjustments, strength-of-schedule calculations, unit metric definitions, or output scaling without explicit new authorization from the owner.

Routine refreshes of game data and rankings computed with the same unchanged model may continue. Cosmetic changes to non-model pages do not authorize methodology changes.

This file is a documented change-control rule, not an automated technical enforcement mechanism. Review scripts and scheduled workflows before deploying changes that might affect the frozen methodology.
